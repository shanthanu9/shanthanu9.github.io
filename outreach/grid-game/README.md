# Two player grid game

The source code for this game was generated by ChatGPT after a series of
prompting and fine-tuning!

## Rules

- The token begins at the bottom-left corner of the grid.
- Players take turns to play. On your turn, move the token either:
    - any number of spaces to the right, or
    - any number of spaces up.

## Goal

Be the one to reach the top-right corner.
